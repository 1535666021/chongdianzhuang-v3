# 财务对账

财务对账将已完成订单按业务月份归集，展示应收、服务费、客户总付、平台扣点、实际到账、材料成本和实际利润。

## 代码位置

| 方面 | 位置 |
|---|---|
| 月度计算 | `src/features/finance/hooks/useFinance.ts` |
| 财务页面 | `src/features/finance/pages/FinancePage.tsx` |
| 统一计算 | `src/shared/utils/orderCalc.ts` |
| CSV 导出 | `src/shared/utils/exportExcel.ts` |

## 汇总口径

| 指标 | 计算方式 |
|---|---|
| 客户总付 | 客户应收加服务费 |
| 实际到账 | 客户总付减平台扣点 |
| 实际利润 | 完工时保存的利润快照 |
| 材料成本 | 完工时保存的材料成本快照 |

旧订单缺少服务费快照时，系统从备注推断服务类型，以保持历史数据可用。
