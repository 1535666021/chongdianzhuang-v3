**FAIL-1：2 字县名提取失败致县级链断裂（低-中危，真实地址场景）**

### 实证（当前 HEAD 生产函数直跑）
- `extractAreaChain('安徽省淮南市寿县安徽寿县寿春镇村委会隔壁')` = `{安徽省, 淮南市, 寿县, 寿春镇}` ✅（delivery T1a 场景，靠"安徽寿县"重复段凑足匹配）
- `extractAreaChain('安徽省淮南市寿县寿春镇 3 号')`（**无重复段的真实常用写法**）= district=**null** ❌

### 根因
`AREA_TAG_DISTRICT_RE = /([^\s省市区县]{2,6}?(?:区|县))(?!小区|社区)/` 字符类排除"县"，量词下限 2——2 字县名（寿县/曹县/单县/冠县/莘县/范县等全国常见）只有 1 个前导汉字，匹配失败 → district=null。
- 3 字及以上县名（长丰县/凤台县）不受影响（已实测长丰县提取正常）
- 连锁影响：2 字县名地址不进县级组、县级点选全域圈不进该单（验收 2"层级累计计数"在该场景失效）

### 整改令
1. `groupTags.ts` 县级正则允许 1 汉字+县（或显式白名单 2 字县名），保持与 foldRepeats/同名互斥逻辑兼容
2. delivery.md 增补 2 字县名场景断言（无重复段写法）：district=县名保留 + 县级点选全域命中
3. 回归 20 条 + tsc + build 复跑（本次 R1 已跑：tsc 0/build 前后检查全过，此 FAIL 为行为层非编译层）
