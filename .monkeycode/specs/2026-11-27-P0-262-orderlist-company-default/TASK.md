## 问题
用户已完成页只看到 11 月一条“到每家”单，担心订单丢失。实证：订单/已完成页沿用 `uiStore.currentCompany` 持久化公司筛选；若上次在统计/财务选了“到每家/未分”，列表会静默只显示该分公司。

## 目标
订单列表（首页/已预约/已完成）默认必须显示全部订单，不得静默继承统计页公司筛选；保留手动公司筛选能力，但当前筛选要显式可见。

## 实现要求
A. OrderList 三个 Tab 默认公司过滤为 `all`；进入页面不读取 `cdz_current_company_v1` 作为默认。可新建 session 级列表状态，不动统计/财务的持久化 currentCompany。
B. 列表顶部保留 CompanyFilter；若用户手动切到本杨/到每家/未分，标题旁或胶囊区常驻显示“当前仅显示：到每家 [一键全部]”，避免误认为丢单。
C. 统计/财务/对账页仍按原 currentCompany 逻辑，不改。
D. 不改 companyHit 判定、不改订单数据、不做迁移。

## 验收
1) 先在统计页选“到每家”，再进已完成页：默认仍显示全部公司订单。  
2) 手动切“到每家”：列表正确过滤，并常驻显示当前公司筛选与一键全部。  
3) 统计页公司选择不被订单页改动反向污染。  
4) npm run build 通过；delivery.md 附脱敏录屏/截图。
