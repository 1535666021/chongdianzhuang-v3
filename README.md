# 充电桩订单助手 V3

> 基于 React + Vite + TypeScript + Tailwind CSS 构建的充电桩安装订单管理系统

## 在线访问
https://1535666021.github.io/chongdianzhuang-v3/

## 本地开发
```bash
npm install
npm run dev
```

## 构建部署
```bash
npm run build
```

## 技术栈
- React 18
- Vite 5
- TypeScript 5
- Tailwind CSS 3
- Zustand 4
- React Router 6
- GitHub Actions 自动部署

## 版本
v3.0.0
