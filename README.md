# 充电桩订单助手 V3

> React + TypeScript + Vite + Tailwind CSS + Zustand

## 线上地址

https://1535666021.github.io/chongdianzhuang-v3/

## 技术栈

- React 18
- TypeScript 5
- Vite 5
- Tailwind CSS 3
- Zustand（状态管理）
- React Router DOM 6
- PWA（渐进式Web应用）

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 部署

Push 到 main 分支自动触发 GitHub Actions 部署到 GitHub Pages。
